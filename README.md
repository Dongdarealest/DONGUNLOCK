# 📱 Installation Guide

## 1. Install Shadowrocket

Download Shadowrocket from App Store.

---

## 2. Import Config

Open Shadowrocket → Config → Download from URL

Paste:

```txt
https://raw.githubusercontent.com/Dongdarealest/DONGUNLOCK/main/DONGUNLOCK
```

---

## 3. Install Certificate

Go to:

Settings → General → VPN & Device Management

Trust Shadowrocket Certificate.

---

## 4. Enable HTTPS Decryption

Inside Shadowrocket:

Settings → HTTPS Decryption → ON

---

## 5. Start Using

Enable the config and enjoy 🚀
