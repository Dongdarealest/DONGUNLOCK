# ② IMPORT CONFIG

Mở Shadowrocket:

```txt
Config → dấu ➕ → Download from URL
```

Dán link config:

```txt
https://raw.githubusercontent.com/Dongdarealest/DONGUNLOCK/main/DONGUNLOCK
```

Sau đó:
- nhấn Download
- chọn config vừa tải
- bật dấu tick xanh

---

# ③ CÀI CHỨNG CHỈ HTTPS

Trong Shadowrocket:

```txt
Settings → HTTPS Decryption → Install Certificate
```

Sau đó:
- nhấn Allow / Cho phép
- cài profile

---

# ④ TIN CẬY CHỨNG CHỈ

Vào:

```txt
Cài đặt → Cài đặt chung → Giới thiệu → Cài đặt tin cậy chứng chỉ
```

Bật:
```txt
Shadowrocket Certificate
```

---

# ⑤ BẬT HTTPS DECRYPTION

Trong Shadowrocket:

```txt
Settings → HTTPS Decryption → ON
```

# ⑥ BẬT VPN
